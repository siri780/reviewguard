ReviewGuard: score one review

Group 18 · Big Data Systems and Algorithms · Stony Brook University

What this is. 400 reviews drawn from the held-out YelpChi test set, 100 from each outcome group (caught, false alarm, missed, correctly passed). Group sizes here are not the real proportions. Scores come from a scikit-learn copy of the logistic regression (test ROC-AUC 0.8514 with network features, 0.7690 without; the Spark model reports 0.8514 and 0.7689). "Fraud" means Yelp's filter flagged the review, not proven fraud. The 32 handcrafted features are anonymous in this dataset.
Contributions are exact for logistic regression: coefficient × standardized feature value, in log-odds. Network features: reviewer count (reviews linked through the same reviewer), same-product reviews, same-product-and-month reviews, and PageRank. In this data, reviewers with no other linked reviews score higher on average, so a count of 0 pushes the score up (the report's campaign analysis found multi-review clusters are less often filtered). Graph features are computed on the full graph including test reviews (transductive), as the report discloses. Source: github.com/siri780/reviewguard.
